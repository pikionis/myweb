# pikioniswebdeveloper — personal site of Petros Pikionis

Astro 5 + GSAP (ScrollTrigger). Static, multi-page site: Home `/`, Services `/services`, Projects `/projects`,
About me `/about`, Contact `/contact`, Blog `/blog`. Site text lives in `src/data/site.ts`; projects and posts are Markdown in `src/content/`.

## Commands
- `npm install` → `npm run dev` (http://localhost:4321) → `npm run build` (output in `dist/`)
- Live at https://onehublabs.com: GitHub Pages, deployed by `.github/workflows/deploy.yml` on every push to `main` and daily (fresh GitHub terrain). The domain is registered at Hostinger; its DNS points at GitHub Pages.

## Structure
- `src/data/site.ts` — text, services (keys `web apps commerce search`: lead / body / chips, claim / summary for the /services card, `includes` = everything it covers, in full), `bots` (AI services & bots: a fifth service on /services and in llms.txt only, not on the home page, which needs real projects), `cardOrder` (the /services order), `howIWork`, stats (shown on /about), UI words (`ui`), page-head defaults (`meta`). Edit content here, not in components; every string lives here so the site can be translated later
- `src/content/projects/*.md` — one file per project (`services:` lists the keys it shows under, none = only on /projects under "More work"; `url` adds "Visit site", `blurb` is its own text on the service sheet, `badge` a label, `metric` + `scope` an engineering card instead of a picture; text in the body gives it its own page). Copy `_template.md`.
- `src/content/blog/*.md` — one file per post; `draft: true` shows only in `npm run dev`. Copy `_template.md`.
- `src/layouts/Site.astro` — every page: the logo's shapes (LogoDefs), Nav, the page, the Contact block as footer, the intro overlay, and `init()` from main.ts
- `src/data/logo.ts` — the onehub logo as path data (generated by `scripts/logo-parts.py` from the brand folder; don't edit by hand). Colours are the `--ink / --cobalt / --ivory` tokens
- `src/components/LogoDefs.astro` defines the shapes once; `Logo.astro` is the header lockup, top left: symbol + wordmark (the link home) and `brand.motto` under the wordmark; it draws them with `<use>`. The name is not in the header (it captions the portrait in the hero and on /about)
- `src/components/LogoIntro.astro` + `src/scripts/intro.ts` — the opening intro ("One Continuous Line"). The head script in `Base.astro` picks the mode before first paint (`html[data-intro]`: full once per session, still with reduced motion, quick = header logo fade) and has a 3s failsafe; `main.ts` waits for `intro.handoff` before the ink title and the entrances. Strings live in `intro` / `brand` in site.ts
- `src/components/` — Nav (split menu + logo), Intro (curtain + hero), Marquee, Services (stacked sheets), Terrain (GitHub, on /about), Contact
- `src/scripts/main.ts` — all motion: curtain, letter/word reveal, light sheet (home only), hero bubbles, section entrances (`data-rise`)
- `src/scripts/splitnav.ts` — the menu (port of KokonutUI Split Nav, MIT): split on the current page, hover gaps, scrub/flick, arrow keys. Top right on desktop; on a phone (≤820px) it floats at the bottom of the screen (the island and the /services cards keep clear of it)
- `src/components/BriefForm.astro` + `src/scripts/brief.ts` — the idea/brief form on /contact (files by drop or picker, 10 MB total). Sending lives only in `send()`: for now FormSubmit's AJAX endpoint (`brief` in site.ts); swap it for our own backend later. Never submit it from tests: intercept `formsubmit.co` — a real send emails Petros.
- `src/scripts/assistant.ts` — the brief assistant's interface (questions → final brief, both streamed). Only `previewAssistant` exists: templates, `npm run dev` only, never shipped. The real one (an endpoint streaming from the model, loaded with the projects and services) implements the same interface in the backend phase.
- `src/components/Services.astro` + `src/scripts/workstack.ts` — home "What I build": service sheets stack over a pinned screen and each sheet's projects stack inside it (one scroll step per sheet/project; `--steps` must match the timeline). It pins on screens ≥861px wide and ≥740px tall, and only if every sheet's words fit beside its projects (measured on load and on resize). On a phone held upright (≤860px wide, ≥560px tall, motion allowed) it holds its own way (`holdPhone`, class `.phone`): each sheet holds the screen in turn under the bar; its title band stays while its words scroll up under it one-for-one with the finger, then its projects stack as on a desktop, then the next sheet slides up over it and the one below scales back. The stack's height is set from the measured words (built once the fonts are in, rebuilt when the width changes). Elsewhere (a short wide screen whose words don't fit, a phone on its side, reduced motion, no JS) it is the plain flow, so no copy is ever cut. Each sheet shows its projects' `blurb` beside the projects, crossfading with the card on top or under the pointer. AI search, marketing & ads shows `proof` (this site) as its card. Project videos lazy-load and play only in view.
- Each service sheet has a background slot (`background` in site.ts: a `--sheet-*` fill token or an image under a 4.5:1 scrim) and a "Read more" button that opens its story
- `src/data/stories.ts` + `src/components/Stories.astro` + `src/scripts/stories.ts` — the service stories (`#story-web`, `#story-saas`, `#story-ecommerce`, `#story-ai-search`). A sheet's "Read more — how I work for you" opens its story as a "thought": small rounds rise from the button and a rounded box grows over the home page, titled with the service; inside, the story plays by itself (`storyPlayer`): each scene's picture draws itself, its words light up, it holds by its word count, then the next; bars, prev/pause/next, a tap on the scene, ←/→ and Space take over, and it pauses while the tab is hidden. After the last scene the pictures FLIP into a grid, all at once, with the CTA and "Play again" (wide box: a storyboard sized by container units so both rows and the CTA fit without scrolling). Reduced motion: it opens straight on the grid with every scene's words. Close, Esc or a click beside the box shrinks it back into the button. The page never moves: while open it is `inert` and wheel/touch are stopped unless the grid itself scrolls (its overflow is left alone, which keeps its layout still); the article is `tabindex=-1` so arriving on its address keeps focus in it. Rendered after `<main>` in index.astro, in the HTML from the start (without script the stories simply follow the services). The CTA goes to `/contact?type=project&service=…`, which pre-selects the brief form's need (`need` in site.ts)
- `src/components/lineart.ts` — the pen the line drawings share (paths that draw on, dots, circles and rounded rects as paths)
- `src/components/StoryArt.astro` (the 23 illustrations, single-line SVG: `sa-d` strokes draw on, `sa-f` dots fade in, `i-*` groups idle, `data-lift` / `data-turn-from` end moves) + `StoryDefs.astro` (the shared person, screen, page, card and parcel symbols). Ink on ivory, one cobalt accent per scene; each picture is authored in its final state, which is how it rests with reduced motion
- `src/components/Contact.astro` — the closing block on every page: invitation, a classic footer (logo slot = `person.logo` in site.ts, pages from `pages`, contact, follow), legal row, then the surname
- `src/scripts/dither.ts` — the surname as an error-diffusion dither field with cursor push and click ripples (port of Componentry Dithered Logo, MIT); the real text stays for layout and as the fallback
- `src/scripts/cascade.ts` — letter cascade on hover for `[data-cascade]` titles (port of Componentry Letter Cascade, MIT); its styles are the `.lc-*` rules in global.css
- `src/pages/services.astro` + `src/scripts/flipstack.ts` — a card per service (`serviceCards()` in projects.ts: the four plus bots, in `cardOrder`) that folds up to reveal the next (port of Componentry Case Study Flip Stack, MIT); card copy is `title` / `claim` / `summary` in site.ts, projects come from the collection, its drawing rests on it as a poster; "How I work" (`howIWork`) runs under the cards
- `src/components/ServiceSheets.astro` + `src/scripts/servicesheets.ts` — each card, opened: its button or a click on the card (not a link) grows it out of its own outline (clip-path) into a sheet over the page, with its drawing playing, the full `includes` list, projects and "Start a project" (`/contact?type=project&service=…`, bots included). Same rules as the stories: page `inert`, wheel/touch stopped unless the sheet body scrolls, Esc / backdrop / close fold it back into the card and return focus, addresses `#service-web|bots|apps|commerce|search`, `tabindex=-1` on the dialog. Its class is `.svc-sheet`: `.sheet` is the home page's light lower page in global.css. Without script the sheets are plain sections after the cards
- `src/components/ServiceArt.astro` + `src/scripts/serviceart.ts` + `src/data/serviceart.ts` (the words in the drawings) — one drawing per card (480×360, `--art-bg` / `--art-ac` from `artAccent` in site.ts), authored as it ends; `artPlayer` plays it from nothing as a short story when the card opens (bots: guest and bot talk until the guest is delighted; web builds and gets AI-ready; apps folds five tools into one; commerce writes, translates, syncs; search answers with your business first), then `.idle`. Parts it moves are named by `data-p`; reduced motion rests drawn
- `src/scripts/glass.ts` — liquid glass carousel + hover ripple in one WebGL2 canvas (port of Componentry Liquid Glass Carousel + Image Ripple Effect, MIT). Lens glows only light what is darker than the paper; never use `pow(x, 2.0)` with negative x in its shaders.
- `src/scripts/projects.ts` — the /projects showcase: title cards for projects without `cover`, open/switch/close (carousel scales down and lifts, video + panel arrive), `?project=id` links
- `src/scripts/island.ts` + `src/styles/island.css` — status island (port of KokonutUI Status Island, MIT): `createIsland(mount)` → `set / update / remove` tasks
- `astro.config.mjs` — the dev toolbar is off: it sat on top of the island
- `src/scripts/ink.ts` — curtain title written in WebGL ink (port of KokonutUI Ink Background, MIT)
- `src/scripts/terrain.ts` — GitHub contribution terrain (port of KokonutUI Activity Terrain, MIT)
- `scripts/github.mjs` — pulls the GitHub calendar into `src/data/github.json`; runs as `prebuild` (`npm run github` by hand)
- `src/styles/global.css` — tokens (dark `:root` / `.theme-dark`; home's lower page is a `.sheet.theme-light` that slides over the hero; inner pages are `.page.theme-light`), `.page-head`, `.prose` for Markdown
- `public/` — put `petros.jpg` (portrait) and vertical project videos here; `og.png` (share card) and `logo.png` (structured-data logo) are rendered from the logo
- `src/pages/llms.txt.ts`, `sitemap.xml.ts`, `robots.txt.ts` — generated from site.ts and the projects; the JSON-LD graph (Person, ProfessionalService, WebSite) and canonical/OG/Twitter meta are in `Base.astro`

## Design direction (the brief wins)
Dark SODA-style world: oversized uppercase Space Grotesk, one electric-blue accent (#4d7cff),
scroll-opening curtain intro, corner labels, services each carrying their real projects,
Lower page turns warm light (#f4f3ef).
Keep this world. Refine, don't replace.

## Skills in `.claude/skills` — use them

## Rules
- Respect `prefers-reduced-motion` (main.ts already gates every effect).
- Small accent text uses `--accent-ink` (contrast ≥4.5:1 in both themes), not `--accent`.
- Icons are inline SVG, never emoji/unicode glyphs. No gradient text, no nested cards.
- No horizontal scroll at 390px.
