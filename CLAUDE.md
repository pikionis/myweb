# pikioniswebdeveloper — personal site of Petros Pikionis

Astro 5 + GSAP (ScrollTrigger). Static, multi-page site: Home `/`, Services `/services`, Projects `/projects`,
About me `/about`, Contact `/contact`, Blog `/blog`. Site text lives in `src/data/site.ts`; projects and posts are Markdown in `src/content/`.

## Commands
- `npm install` → `npm run dev` (http://localhost:4321) → `npm run build` (output in `dist/`)
- Live at https://onehublabs.com: GitHub Pages, deployed by `.github/workflows/deploy.yml` on every push to `main` and daily (fresh GitHub terrain). The domain is registered at Hostinger; its DNS points at GitHub Pages.

## Structure

- `src/data/servicespage.ts` — every word of /services in `Copy` (en/el): hero, picker, the four sections (title, short name, promise, bullets, chips, proof, timeline, `weeks` for the timelines, `startingFrom` = null hides the price, cta), how we work (each step names its story picture and its crop), the timelines, the FAQ (12 pairs, with chip names), the form (`budgets` empty = the budget field hidden), the words in the drawings. ## Design direction (the brief wins)
Dark SODA-style world: oversized uppercase Space Grotesk, one electric-blue accent (#4d7cff),
scroll-opening curtain intro, corner labels, services each carrying their real projects,
Lower page turns warm light (#f4f3ef).
Keep this world. Refine, don't replace.

## Rules
- Respect `prefers-reduced-motion` (main.ts already gates every effect).
- Small accent text uses `--accent-ink` (contrast ≥4.5:1 in both themes), not `--accent`.
- Icons are inline SVG, never emoji/unicode glyphs. No gradient text, no nested cards.
- No horizontal scroll at 390px.
