# pikioniswebdeveloper

Personal site — Astro + GSAP.

```
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
```

Edit content in `src/data/site.ts`. Add your portrait as `public/petros.jpg` and set `photo: '/petros.jpg'`.
For a project video in the bubble panel, put a vertical mp4 in `public/videos/` and set `video` on that brand.

Design skills for Claude Code are in `.claude/skills` (see CLAUDE.md).
